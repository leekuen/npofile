## 附錄：Nielsen 十大可用性原則對照

本 skill 是這十條在「及格門檻」上的濃縮（這張對照表：源專案 v4.35.0）。列出來是為了日後 review 能反查**有沒有原則失守**，
不是要照著背——實際執行看核心 `SKILL.md` 的〈開工前檢查〉與各節。

| # | 原則 | 落在本 skill 哪裡 |
|---|---|---|
| ① | 可視的系統狀態 | §3 狀態與回饋（四態、即時回饋、狀態徽章窮舉） |
| ② | 貼近真實世界 | §1 佈局層次、§4 欄位順序、§5 自然順序；**字詞交給 `ux-writing`** |
| ③ | 使用者掌控與自由 | §8 出口與掌控（**不含 undo**，見該節）、§10 拿掉條件的出口永遠在 |
| ④ | 一致性與標準 | §5 一致性、§10 篩選面板全站同一套 |
| ⑤ | 錯誤預防 | §2 錯誤預防階梯、§4 表單驗證 |
| ⑥ | 認得優於記得 | §4 能選不要打、能顯示不要記 |
| ⑦ | 彈性與效率（加速器） | **刻意不收**——本 skill 只做到及格，收它會鼓勵做沒人要的加速功能；§5〈快捷鍵克制〉已是這條在及格線上的表達 |
| ⑧ | 美學與極簡 | §6 視覺基本盤、§7 克制、§9「不選＝全部」要看得出是個值 |
| ⑨ | 錯誤的辨識／診斷／修復 | §3 提示三級、§4 錯誤就地顯示＋退回帶著舊內容 |
| ⑩ | 說明與文件 | §7 克制（說明貼在脈絡裡）、§3「輔助說明」那一級 |
