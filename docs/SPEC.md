## 1. 產品概述

- **一句話定位**：讓大眾查得到非營利組織的受捐紀錄、資金來源（財閥／金主），以及受裁罰紀錄的公開透明平台。
- **主要角色**：
  - 公眾／捐款人（查詢者）：查詢非營利組織的受捐、資金來源、裁罰紀錄。
  - 非營利組織（被查詢對象）：資料主體，本身不一定登入系統。
  - 管理員／編輯（資料維護）：負責輸入／審核捐款、金主、裁罰等資料的幕後人員。
- **範圍邊界**：目前只收錄兩個政府公開來源（衛福部公益勸募管理系統、財政部非營利事業機關團體資料集）；
  集資平台、司法院裁判書、臉書與組織官網尚未接（LK-05）。不做金流、不寄信（沒有 Email 驗證與忘記密碼）、尚無正式部署環境。

## 3. 功能細節

> 每個功能一節：誰用、入口在哪、操作流程、規則與邊界、驗收標準。
> 對應的功能票在 frontmatter `spec:` 欄位指回本節（例：`spec: docs/SPEC.md#31-xxx`）。

### 3.1 管理員後台（組織資料 CRUD）🚧

- **誰用**：管理員／編輯，電腦瀏覽器，`/admin/`（後端網址）。只有管理員帳號進得去，捐款人帳號會被擋。
- **資料**：組織（統一編號 8 碼為唯一識別、名稱、團體類型、負責人、地址、電話、官網、縣市、勸募用途、營運狀態：營運中／已註銷／已撤銷／擅自歇業），
  底下四類：年度募款、捐款紀錄（可標匿名）、捐款專案、受裁罰紀錄；每筆都記來源名稱與網址。
- **操作**：依統編或名稱搜尋，依營運狀態、縣市、團體類型篩選；組織頁內一起編輯四類資料。
- **規則**：管理員改過的基本欄位自動「手動鎖定」，爬蟲不覆蓋；「解除手動鎖定」動作可解開。匿名捐款在前台與 API 一律顯示「匿名」。

### 3.2 爬蟲與審核佇列 🚧

- **誰用**：管理員；正式環境由排程呼叫 `manage.py crawl <來源>`。
- **來源**：財政部非營利名冊（統編、名稱、縣市、營運狀態）；衛福部公益勸募團體頁（基本資料、歷年募款、最近幾筆勸募活動、近五年裁處）。
  每秒最多一個請求；同內容重抓不重複。
- **審核機制**：每個來源可設「自動上架」或「先審核」（政府來源預設自動上架）。先審核的資料在「爬蟲資料（審核佇列）」，預設只列待審核，可批次核准或退回；核准才寫進組織資料。
- **紀錄**：每次執行一筆紀錄（抓到、新資料、上架、待審核、失敗、錯誤訊息）；後台可「立即試跑」每個來源 5 筆。

### 3.3 組織列表、組織資訊頁與揭露指數 🚧

- **誰用**：公眾／捐款人，不用登入，手機或電腦。
- **首頁**：三個統計（收錄組織數、有公益勸募紀錄的組織、近五年受裁罰的組織）；搜尋名稱或 8 碼統編，篩縣市、營運狀態，排序揭露指數高到低（預設）或名稱；
  已套用的條件以標籤顯示、可單獨移除；每頁 20 筆。
- **組織頁** `/orgs/<統編>`：名稱、統編、類型、營運狀態、近五年受裁罰次數（有才標示）、揭露指數（可展開四項分數）；
  分頁：基本資料／過往受捐款資訊（歷年募款表，不列 0／0 年度；大額捐款人排行前 10，只列具名）／捐款專案／受裁罰紀錄。每類資料附出處，沒資料時說明原因。
- **揭露指數**（0～100）：基本資料 30（統編、類型、地址、電話、官網、用途各 5）＋近五年有實募或有捐款紀錄 25＋有捐款專案 20＋有募到款的專案中已成果備查的比例 × 25。裁罰不扣分、另外標示。

### 3.4 捐款人註冊登入與留言 🚧

- **誰用**：公眾／捐款人；管理員審核。
- **帳號**：Email＋顯示名稱＋密碼（至少 8 碼、不能全數字或太常見）；註冊後直接登入。同 Email 同來源連續 5 次登入失敗鎖 15 分鐘。
- **留言**：組織頁最下方；未登入看到登入連結。送出後作者看到「審核中」，管理員核准後所有人看得到；退回的只有作者看得到「未通過」與原因。
  1～1000 字、每分鐘最多 3 則、作者可刪自己的、不能修改。Email 永不公開。
- **後台**：留言清單預設列審核中，可批次核准／退回；捐款人清單可停用、恢復帳號。

## 4. 非功能事項

> 效能、資安、相容性等跨功能的承諾與現況；沒有就留空。

- 祕密走環境變數（`server/.env.example`）；正式環境沒設 `DJANGO_SECRET_KEY` 拒絕啟動。登入／註冊檢查 CSRF，前台經同源 `/api/*` 轉給後端。
- 正式環境資料庫為 PostgreSQL（`DATABASE_URL`），目前只驗過設定解析，尚未實際連 PostgreSQL 跑過；本機用 SQLite。
- 揭露指數的「近五年」隨日期移動，需每天跑 `recompute_scores`。
