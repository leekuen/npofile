# NPOFile 前台（Next.js 16）

```
npm install
npm run dev      # http://localhost:3000，/api/* 轉給 API_BASE（預設 http://127.0.0.1:8000）
npm run lint
npm run build
```

環境變數：`API_BASE`（後端位址，伺服器端讀資料與 rewrites 都用它）。

專案規範見 repo 根目錄的 `AGENTS.md`；Next.js 16 的變更見 `AGENTS.md`（本資料夾）與 `node_modules/next/dist/docs/`。
