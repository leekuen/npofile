## 目的（要解決什麼問題）

LK-02 只接了兩個政府來源。架構圖還列了智邦公益館、一起夢想、集資平台（嘖嘖、挖貝）、組織官網／臉書、司法院裁判書與行政裁罰查詢；接上之後捐款專案與裁罰資料會更完整。

## 使用角色與情境

- 管理員／編輯：在後台啟用新來源；這些非官方來源抓回來的資料預設進待審核清單。

## 逼問紀錄

- 問（agent 代決）：司法院裁判書能不能直接抓？／答：司法院資料開放平臺的裁判書 API 要先註冊帳號取得 Token，而且只在每天 00:00～06:00 提供服務；裁判被移除時要同步刪除／因此：需要使用者先註冊帳號，動工前要拿到帳號。
- 問（agent 代決）：臉書能不能抓？／答：臉書禁止未經授權的爬取，要走官方 Graph API 與審核／因此：這張票先不含臉書，除非有 API 權限。
- 問（使用者 2026-11-27）：先做哪一塊？／答：先做司法院判決書，補上詐欺、侵占這類比衛福部違規公告更嚴重的紀錄；舉例是更生團契桃園少年之家前執行長張進益案／因此：這次只做司法院判決書，集資平台與官網留在這張票之後再做。
- 問（agent 代決）：張進益案查得到判決嗎？／答：2026-11-27 用裁判書查詢網站以機構全名查，7 筆都不是這件刑案：2 筆是別人的案子裡被指定的捐款對象、1 筆是機構的車被撞、其餘是員工薪資扣押與章程修改。刑案 2025-08 才起訴、含性侵部分，判決可能還沒出來，出來時也可能依性侵害犯罪防治法遮掉機構名稱／因此：判決書只能補「已判決、而且寫出機構名稱」的案子；起訴階段只能靠新聞，不在這張票。
- 問（agent 代決）：機構名稱出現在判決裡就算紀錄嗎？／答：不算，上面 7 筆全是誤報／因此：只收刑事與行政判決、刑事只收侵占詐欺背信偽造性侵等罪名，排除「捐款給該機構」的段落，判斷機構的角色（被告／當事人／人員涉案）寫進內容，全部進待審核，不自動上架。
- 問（agent 代決）：怎麼抓？／答：API 只給「7 天前那天異動的判決清單」，沒有搜尋；裁判書查詢網站有防機器人，不能爬；歷年資料只有每月整包下載（RAR）／因此：每天凌晨跑 API 接新判決，舊資料用解壓後的整包目錄匯入（`crawl judicial --archive <資料夾>`）。
- 問（agent 代決）：判決被司法院撤下怎麼辦？／答：API 規定撤下的判決使用者要跟著刪／因此：API 回「查無資料」就刪掉我們這邊同一則判決的待審資料與已上架紀錄。
- 問（agent 代決）：非官方來源要不要自動上架？／答：不要，預設進待審核／因此：沿用 LK-02 的審核機制。

## 需求細節

- 逐一評估並接上：智邦公益館、一起夢想、嘖嘖、挖貝、組織官網徵信頁、司法院裁判書 API（需帳號）。
- 每個來源都走 LK-02 的爬蟲架構與審核佇列，預設「需人工審核」。
- 欄位權限：沒有新欄位出現在新地方或開給新角色（這張票只增加資料來源，資料照 LK-01／LK-02 的權限顯示）。
- 誰能改：只有管理員／編輯。
