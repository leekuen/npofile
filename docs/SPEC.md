> 性質：**本專案目前實際提供哪些功能、每個功能怎麼運作、做到什麼程度的單一事實來源。**

## 0. 這份文件是什麼

用非工程師也讀得懂的方式，描述本專案**目前**提供哪些使用者可見功能。功能改了就要更新本文件——
**寫點在合流 `stage` 的那一次**（feature 分支與開票階段不動它；還沒上 `stage` 的規劃住在票裡）。

### 狀態圖例

| 狀態 | 意義 |
|------|------|
| ✅ 已完成 | 已實作、所有介面到位並通過驗證，可用。 |
| 🚧 進行中 | 已上 `stage`，但尚未驗收或功能未完整。 |
| ⏳ 未開始 | （舊制）已規劃但尚未動工。**不再新增**——還沒上 `stage` 的功能不寫進本文件；既有的 ⏳ 列在該功能上線或作廢時順手處理。 |
| 🗑 已下線 | 曾經有、已移除。 |

> `⭐` = MVP 範圍（有 MVP 界定的專案才用，避免把後期功能誤當 MVP）。

## 1. 產品概述

- **一句話定位**：讓大眾查得到非營利組織的受捐紀錄、資金來源（財閥／金主），以及受裁罰紀錄的公開透明平台。
- **主要角色**：
  - 公眾／捐款人（查詢者）：查詢非營利組織的受捐、資金來源、裁罰紀錄。
  - 非營利組織（被查詢對象）：資料主體，本身不一定登入系統。
  - 管理員／編輯（資料維護）：負責輸入／審核捐款、金主、裁罰等資料的幕後人員。
